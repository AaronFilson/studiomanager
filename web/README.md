# Studio Manager web

React 19 + Vite 8, TanStack Router (file-based routes) and TanStack Query, with sign-in through Microsoft Entra External ID (MSAL, redirect flow with PKCE).

## Run locally

From the repo root (Node 24; pnpm comes from the `packageManager` field via corepack):

```sh
corepack pnpm@12.14.0 install
cp web/.env.example web/.env.local   # then fill it in, see below
corepack pnpm@12.14.0 --filter @studiomanager/web dev
```

The dev server runs on http://localhost:5173 and proxies `/api` to the API on http://localhost:8080 (see `/api`). Without the auth settings the app shows a "sign-in is not configured" page instead of crashing.

Other scripts: `typecheck`, `lint`, `test` (Vitest + Testing Library + MSW), `build` (output in `web/dist`).

## Settings

Vite reads these at build time (`web/.env.local` locally, pipeline variables in CI):

| Variable | Example | Notes |
|---|---|---|
| `VITE_ENTRA_CLIENT_ID` | `00000000-…` | The SPA app registration in the External ID tenant |
| `VITE_ENTRA_AUTHORITY` | `https://<subdomain>.ciamlogin.com/` | The tenant's authority; its host becomes MSAL's `knownAuthorities` |
| `VITE_API_SCOPES` | `api://<api-client-id>/access_as_user` | Space-separated |
| `VITE_API_BASE_URL` | `https://<app>.<env>.<region>.azurecontainerapps.io` | Empty locally (same origin, through the proxy) |

The SPA registration needs a **Single-page application** redirect URI for each origin the app runs on, ending in `/`: `http://localhost:5173/` and the Static Web App URL. MSAL always redirects to the origin root and then returns to the page that started sign-in.

## Where the API client comes from

`@studiomanager/api-client` (in `packages/api-client`) is generated by [Hey API](https://heyapi.dev) from the OpenAPI contract at `api/src/main/openapi/studiomanager.yaml`: typed SDK functions plus TanStack Query options (`getMeOptions`, `getStudioOptions`, `createStudioMutation`). After changing the contract, run `corepack pnpm@12.14.0 run generate` from the repo root and commit the output; CI fails if the committed client is stale.

## Deployment

The build is deployed to Azure Static Web Apps. `public/staticwebapp.config.json` rewrites unknown paths to `index.html` for client-side routing, caches hashed assets for a year, and sets security headers. Its Content-Security-Policy allows API calls to `*.azurecontainerapps.io` and sign-in at `*.ciamlogin.com`; update `connect-src` if the API moves to a custom domain.
